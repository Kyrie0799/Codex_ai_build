# Six-Month Codex Community Contribution Roadmap

**Proposed focus:** Practical Codex education for non-traditional builders, founders and finance professionals. This is a proposed plan, not a claim of past events.

| Month | Contribution | Format |
|---|---|---|
| 1 | From financial problem to ETF Pulse | Public build walkthrough |
| 2 | Codex for non-engineer founders | Practical tutorial |
| 3 | Building financial data workflows | Technical case study |
| 4 | Client financial intelligence workflow | Architecture lesson |
| 5 | From prototype to deployed product | Build-in-public series |
| 6 | Building towards investor intelligence | Retrospective and roadmap |

Based in Tallinn, Estonia, with professional and founder experience connected to India. I would like to create useful content for an international audience and explore a small Tallinn-based builder session once a consistent content cadence is established. I have not yet organised formal events, so this is an intention rather than an existing track record.
