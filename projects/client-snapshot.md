# Client Snapshot

**Status:** Internal product development

Client Snapshot collects client financial information through a frontend workflow and organises it for analysis that can support financial planning.

The analysis areas described for the product include mutual fund overlap, sector exposure, portfolio imbalances, liquidity profiling and emergency-fund preparedness.

## Intended workflow
1. Collect relevant client information.
2. Structure it into a consistent financial profile.
3. Run portfolio and financial-position analysis.
4. Surface observations and questions for adviser review.
5. Use the analysis as an input to financial planning.

This is an adviser-support workflow, not a replacement for professional judgement. Public demonstrations must use synthetic data.
