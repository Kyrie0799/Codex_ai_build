# Advisoira Backend and Integrations

**Status:** Supporting infrastructure

The products use supporting services and integrations identified by the founder as including:
- Supabase for backend and data infrastructure.
- GitHub for source control and development workflows.
- Resend for email delivery.
- APIs for external data and application services.

This is a high-level inventory, not a complete system specification. Do not publish schema details, endpoint designs, credentials, environment configuration or sensitive implementation information.

Security basics: never commit API keys or tokens; use synthetic data in demos; keep client data and private repositories private; review access controls before showing backend interfaces.
